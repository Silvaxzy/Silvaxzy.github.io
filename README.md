# Portfólio — Bruno Silva

Portfólio pessoal com identidade visual preta e azul, animações e layout responsivo.

🔗 **Site:** https://silvaxzy.github.io

## 🛠️ Tecnologias

- **Next.js** + **React** + **TypeScript**
- **Tailwind CSS** para o visual
- **Framer Motion** para as animações de entrada, hover e parallax
- **GSAP (ScrollTrigger)** para a timeline animada
- **Lucide Icons**

## ✨ Destaques

- Hero com símbolo de raios animado e efeito parallax ao mover o mouse
- Partículas flutuantes no fundo e luz que acompanha o cursor
- Projetos com filtro por categoria e cards com inclinação 3D
- Habilidades com barras e indicadores circulares animados
- Timeline de experiência que se desenha conforme a rolagem
- Formulário de contato, SEO e acessibilidade (navegação por teclado e respeito ao "reduzir movimento")

## 🚀 Rodar no computador

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## ✏️ Editar o conteúdo

Todos os textos ficam em `src/data/portfolio.ts`.
Fotos ficam na pasta `public` (`foto.jpg` e `projetos/`).
